# CSCI 384 Checkers AI

Group project for CSCI 384 Artificial Intelligence.

This project implements a Checkers AI in Python using Minimax, Alpha-Beta pruning, and heuristic evaluation.

## Project Structure
- `src/` - main game and AI code
- `experiments/` - experiment scripts
- `results/` - experiment results
- `docs/` - project documents

More setup and run instructions will be added as development continues.
